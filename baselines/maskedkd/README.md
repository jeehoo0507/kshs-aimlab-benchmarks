# MaskedKD baseline

English · [한국어](../../docs/ko/baselines/maskedkd/README.md)

The reference is the [MaskedKD paper](https://arxiv.org/abs/2302.10494) and its [official implementation](https://github.com/effl-lab/MaskedKD), pinned to commit `96d052da7346441e2425876a9ad37ff8c87fe383`.

```bash
bash scripts/fetch_maskedkd.sh
```

This clones the source into the ignored `external/MaskedKD/` directory. Author-trained comparison weights are available under [checkpoints](../../checkpoints/README.md). Record the code commit and dataset manifest or metadata hash with each result.
