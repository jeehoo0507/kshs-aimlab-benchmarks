# GPU 가이드

[English](../../GPU.md) · 한국어

실험을 시작하기 전에 사용 가능한 GPU 메모리와 다른 프로세스를 확인하세요.

```bash
nvidia-smi
watch -n 2 nvidia-smi
```

RTX A5000의 전체 메모리가 24 GiB여도 그만큼 모두 사용할 수 있는 것은 아닙니다. **대표 작업 하나의 최대 VRAM 사용량**을 측정한 뒤, 현재 남은 메모리에 대기 중인 작업이 몇 개까지 들어가는지 계산하세요.

```bash
python3 scripts/gpu_capacity.py --peak-gib 2.26 --pending 12
```

`2.26`은 측정한 작업 하나의 최대 사용량으로, `12`는 대기 중인 독립 작업 수로 바꾸세요. 이 명령은 `nvidia-smi`에서 현재 남은 VRAM을 읽어 메모리 기준 최대 병렬 작업 수를 계산하며, 작업을 실행하지는 않습니다. 전체 GPU에 **2.5 GiB의 여유 공간**을 남기고, 작업당 메모리 할당과 프로세스 간 차이를 고려해 측정값의 25%와 0.5 GiB를 추가로 잡습니다. 병렬 작업 수가 1·2·4개로 고정된 것은 아닙니다. 작업을 하나씩 시작하고 매번 남은 VRAM을 다시 확인해 여유 공간을 침범하기 전에 추가 실행을 멈추세요. 처리량이 중요하다면 가능한 병렬 작업 수마다 시간당 완료된 작업량을 비교하세요. 가장 많이 띄운 구성이 항상 가장 빠르지는 않습니다.

중단된 실험은 동일한 데이터, Teacher 체크포인트, 설정을 사용해 가장 최근에 저장한 epoch부터 재개하세요. 정확도와 함께 학습 시간과 최대 VRAM 사용량도 기록하세요. `scripts/check_assets.py`는 파일만 검사하며 GPU를 사용하지 않습니다.

[MaskedKD 기준 실험 실행기](reference/README.md)는 Student의 실제 VRAM 사용량을 측정한 뒤 `--jobs auto`에서 같은 계산을 사용합니다. 비용을 비교할 수 있도록 seed 0을 단독으로 학습하므로, 동시에 실행할 수 있는 나머지 seed는 1과 2뿐입니다. **이 실험에서 최대 2개가 병렬로 실행되는 것은 seed 구성 때문이지 GPU의 한계가 아닙니다.** Student를 순차적으로 학습하려면 `--jobs 1`을 사용하세요. 로그와 epoch별 재개 체크포인트는 `outputs/reference/`에 저장됩니다.
